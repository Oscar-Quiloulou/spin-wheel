Semaine 1 – Fondations du Hacking Éthique

Cette première semaine pose les bases essentielles du hacking éthique. Avant d’utiliser des outils, avant de lancer un scan, avant même de toucher une machine virtuelle, il faut comprendre la philosophie, le cadre légal, les responsabilités et la méthodologie mentale d’un hacker éthique.

1. Comprendre la logique du hacking éthique

Le hacking éthique n’est pas une activité de “piratage gentil”. C’est une discipline professionnelle qui repose sur un principe simple :

“Penser comme un attaquant, agir comme un défenseur.”

Cela signifie que tu dois apprendre à analyser un système comme si tu voulais le compromettre, mais avec l’objectif de le protéger. Le hacker éthique est un expert en sécurité qui :

  • identifie les failles avant les criminels,
  • teste les défenses,
  • évalue les risques,
  • propose des solutions concrètes.

2. Les trois profils de hackers

Pour comprendre ton rôle, il faut connaître les trois grandes catégories de hackers :

White Hat – Le hacker éthique

Il travaille avec autorisation, dans un cadre légal, pour améliorer la sécurité. Il documente tout, respecte les règles, et ne cause jamais de dommages.

Black Hat – Le cybercriminel

Il exploite les failles pour voler, détruire, extorquer ou nuire. Il agit sans autorisation et viole la loi.

Grey Hat – Entre les deux

Il peut découvrir des failles sans autorisation, parfois pour “aider”, mais cela reste illégal. Il n’a pas d’intention criminelle, mais il enfreint la loi.

3. Le cadre légal : ce que tu peux faire, ce que tu ne peux pas faire

En France, accéder à un système sans autorisation est un délit puni par :

  • amende,
  • interdiction professionnelle,
  • peine de prison selon la gravité.

Actions illégales (interdites même pour apprendre)

  • Scanner les ports d’un site qui ne t’appartient pas
  • Tester un mot de passe sur un service public
  • Accéder à une base de données sans autorisation
  • Exploiter une faille sur un site “pour voir”

Actions légales (autorisées pour apprendre)

  • Tester une machine virtuelle que tu as installée
  • Utiliser des plateformes d’entraînement (TryHackMe, HTB, OverTheWire)
  • Participer à des programmes bug bounty autorisés
  • Analyser ton propre réseau local

4. Le périmètre : la règle d’or du hacking éthique

Lors d’un test d’intrusion, tu reçois un document appelé “scope” (périmètre). Il définit :

  • les machines autorisées,
  • les adresses IP,
  • les applications,
  • les limites à ne pas dépasser.

Si une machine n’est pas dans le périmètre, tu n’y touches pas. C’est la frontière entre un test légal et un délit.

5. La mentalité du hacker éthique

Le hacking éthique est une discipline qui demande :

  • Curiosité : comprendre comment les systèmes fonctionnent.
  • Patience : certaines failles prennent des heures à trouver.
  • Rigueur : documenter chaque action.
  • Analyse : comprendre les risques.
  • Éthique : respecter les règles.

6. Les responsabilités d’un hacker éthique

Un hacker éthique doit :

  • respecter le périmètre défini,
  • ne jamais causer de dommages,
  • protéger les données sensibles,
  • minimiser les perturbations,
  • rendre un rapport clair et professionnel.

Semaine 2 – Réseaux & Linux : Les Fondations Techniques du Hacker Éthique

Cette semaine est cruciale : tu vas apprendre les bases techniques qui permettent à un hacker éthique de comprendre comment les machines communiquent, comment les services fonctionnent, et comment interagir avec un système via Linux. Sans ces fondations, impossible de comprendre Nmap, Burp, Metasploit, les failles web ou les attaques réseau.

1. Introduction aux réseaux : comment les machines communiquent

Un réseau informatique est un ensemble de machines qui échangent des données. Pour comprendre le hacking, il faut comprendre comment ces données circulent. Le modèle le plus utilisé pour expliquer cela est le modèle TCP/IP.

1.1 Le modèle TCP/IP

TCP/IP est composé de 4 couches :

  • Couche Application – HTTP, HTTPS, FTP, DNS…
  • Couche Transport – TCP, UDP
  • Couche Internet – IP (routage des paquets)
  • Couche Accès réseau – Ethernet, Wi-Fi

1.2 Les adresses IP

Une adresse IP identifie une machine sur un réseau. Exemple : 192.168.1.42 Il existe deux types :

  • IPv4 – le plus utilisé (4 nombres entre 0 et 255)
  • IPv6 – plus récent, beaucoup plus d’adresses

1.3 Les ports

Un port est une “porte logique” qui permet à un service de communiquer. Exemple :

  • Port 80 → HTTP
  • Port 443 → HTTPS
  • Port 22 → SSH
  • Port 21 → FTP
Lors d’un pentest, tu scannes les ports pour savoir quels services sont actifs.

1.4 TCP vs UDP

TCP : fiable, vérifie que les données arrivent (web, email).
UDP : rapide, pas de vérification (jeux, streaming).

2. Les protocoles essentiels pour le hacking

Voici les protocoles que tu dois absolument connaître :

  • HTTP/HTTPS – base du web, cible principale des failles
  • DNS – résout les noms de domaine
  • SSH – accès distant sécurisé
  • FTP – transfert de fichiers
  • SMTP – emails
Comprendre ces protocoles te permettra d’analyser le trafic, d’intercepter des requêtes, et de comprendre les failles web.

3. Introduction à Linux : l’OS du hacker

La majorité des outils de hacking fonctionnent sur Linux. Pourquoi ?

  • Open-source → tu peux tout analyser
  • Puissant pour le réseau
  • Stable et rapide
  • Outils de sécurité intégrés
Les distributions les plus utilisées :
  • Kali Linux – orientée pentest
  • Parrot OS – orientée sécurité
  • Ubuntu – stable, parfait pour apprendre

4. Les commandes Linux essentielles

Voici les commandes que tout hacker doit connaître :

Navigation

    cd dossier/        → entrer dans un dossier
    cd ..              → revenir en arrière
    ls                 → lister les fichiers
    pwd                → afficher le chemin actuel

Manipulation de fichiers

    cp fichier1 fichier2   → copier
    mv fichier1 fichier2   → déplacer / renommer
    rm fichier              → supprimer
    mkdir dossier           → créer un dossier
    touch fichier.txt       → créer un fichier vide

Réseau

    ifconfig / ip a         → afficher les interfaces réseau
    ping adresse             → tester la connexion
    netstat -tulnp          → voir les ports ouverts
    curl http://site.com    → récupérer une page web

Permissions

    chmod 755 fichier       → changer les permissions
    sudo commande           → exécuter en administrateur

5. Préparer ton environnement de hacking

Pour t’entraîner légalement, tu dois créer un environnement isolé :

  • Installer une machine virtuelle (VirtualBox)
  • Installer Kali Linux ou Ubuntu dedans
  • Installer une machine vulnérable (Metasploitable2, DVWA)
  • Créer un réseau interne entre les deux
Cela te permettra de tester des attaques sans aucun risque légal.
